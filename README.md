# Prep Simulator for USAT

A free Android app by [HomiLabs](https://homilabs.org): 20 full mock tests for each HEC USAT category (E, M, CS, GS, COM, A), built to HEC's published content weightages, with Part II essay practice, study notes, memory tricks, explanations and guidance. Independent practice material, not affiliated with HEC or its Education Testing Council.

- App: Flutter, in `lib/`. Project notes: `CLAUDE.md`.
- Content: `content/`, built into `assets/data/` by `tool/build_content.py`.
- Website: `website/`, live at https://usat.homilabs.org.
- Release and hosting: `docs/release-and-hosting.md`.
